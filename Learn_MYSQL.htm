Learn MYSQL and Mysql-Connector

Part one install mysql and create user

* install mysql

To install MYSQL in Linux, we can use the command:
[username]$ sudo apt install mysql-server

But to install the mysql-connector, you need to install the venv first, the command to install venv and install the mysql-connector:
venv
1- sudo apt indtall venv
2- pyhton3 -m venv venv_name
3- source venv_name/bin/activate
mysql-connector:
1- (venv_name)[username]$ pip install mysql-connector

* create user in mysql

To set up your account, you need to enter these commands in a row (about each command described)

command one with this command, you will enter MYSQL
(venv_name)[username]$ sudo mysql

commands two With these two commands, you can create your account and then give it access to it, and then you press another command, which is nothing special, and then you leave with the last command.
mysql> CREATE USER 'user_name'@'localhost' IDENTIFIED BY 'password';
msyql> GRANT ALL ON * . * TO 'username'@'localhost';
mysql> FLUSH PRIVILEGES;
mysql> exit;
